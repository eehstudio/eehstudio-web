# EEH STUDIO

포트폴리오와 소유자 전용 콘텐츠 관리 화면.

- `/`: 기존 19개 프로젝트·5개 노트 및 공개한 CMS 콘텐츠
- `/admin`: ChatGPT 소유자 로그인, 프로젝트·노트 추가와 수정, 원본 이미지 업로드, 임시 저장, 비공개 미리보기, 게시·게시 중단, 이전 저장본 복원, JSON 백업
- 기본 사이트 원본은 `site/index.html`, 이미지·3D·도면은 `public/`에 있습니다.
- `lib/cms/seeds.json`은 최초 편집용 문서입니다. 저장한 초안과 공개본은 D1에서 독립적으로 관리합니다. 업로드는 R2에 보관합니다.
- `CMS_ADMIN_EMAIL`을 Sites의 서버 환경 변수로 설정합니다. 클라이언트 코드와 저장소에 값을 넣지 않습니다. 관리자 API는 플랫폼 인증과 소유자 이메일, 쓰기 요청의 동일 출처를 확인합니다.
- CMS 변경 사항은 ‘게시하기’ 후 공개 페이지를 다시 열면 반영됩니다. 코드 재배포는 저장한 콘텐츠와 이미지를 초기화하지 않습니다.
- 기존 프로젝트는 기본 정보와 화면에서 선택한 텍스트·이미지·링크를 수정하며, 본문 블록을 추가할 수 있습니다. 기존 3D 모델의 형상 편집은 코드/모델 작업 영역입니다.

## 검증

`node tests/cms.mjs` — 실제 SQLite를 사용하는 인증, 초안/게시, 버전 충돌, 복원, 업로드 및 비공개 미리보기 검증.

사이트 빌드는 Sites 플러그인의 `build-site.mjs`를 사용합니다. `dist/`는 생성 결과이며 직접 편집하지 않습니다. 원본 코드와 마이그레이션은 저장소에서 관리합니다.
